# 📊 Quiz App — Results to Google Sheets

A modern, responsive quiz web app that collects user answers, calculates scores, and automatically saves results to Google Sheets.

## ✨ Features

* 🧠 Interactive multiple-choice quiz
* 📈 Real-time progress bar
* 👤 User name input
* 🎯 Instant score calculation with visual feedback
* 🔄 Animated score ring
* ☁️ Automatic submission to Google Sheets
* 📱 Fully responsive design
* 🎨 Clean UI (DM Sans + Fraunces fonts)
